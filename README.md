# Video Frame Explorer

Браузерное приложение для детального анализа видео, навигации по кадрам и
извлечения изображений с анализом цветовой палитры. Работает **полностью
локально** — видео никуда не загружается, всё обрабатывается прямо во вкладке
браузера.

![Video Frame Explorer](https://img.shields.io/badge/100%25-client--side-8b5cf6) ![No build](https://img.shields.io/badge/build-none-10b981) ![Deps](https://img.shields.io/badge/dependencies-0-ec4899)

## Возможности

| Раздел | Что делает |
|--------|------------|
| **Загрузка** | Drag & Drop или выбор файла. MP4 / WebM / MOV / AVI / MKV* |
| **Сегменты** | Делит видео на 2–100 равных частей, по одному кадру из начала каждой |
| **Детали сегмента** | 30 кадров, равномерно распределённых по сегменту |
| **Сужение (Focus)** | 11 кадров с шагом 0.1 с (±0.5 с), рекурсивное углубление |
| **Свободный режим** | Слайдер по времени с точностью 0.1 с |
| **Диапазон** | До 60 кадров между двумя точками, настраиваемыми слайдерами |
| **Групповые операции** | Выбор кадров, экспорт PNG в ZIP, экспорт палитр в Markdown |
| **Цветовая палитра** | До 20 доминирующих цветов: HEX, RGB, проценты, CSS-переменные, JSON |

\* Поддержка контейнеров зависит от кодеков браузера. MP4 (H.264) и WebM
поддерживаются везде; MOV/AVI/MKV — там, где браузер умеет их декодировать.

## Запуск

Никакой установки и сборки не нужно. Достаточно открыть `index.html`:

```bash
# вариант 1 — просто открыть файл
open index.html          # macOS
xdg-open index.html      # Linux

# вариант 2 — локальный сервер (на случай ограничений file://)
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Архитектура

Чистый ванильный стек, без фреймворков и без шага сборки:

```
index.html    — разметка и подключение скриптов
styles.css    — оформление (тёмная тема, glassmorphism, акценты violet/pink/green)
zip.js        — собственный ZIP-писатель (метод STORE + CRC32), без зависимостей
palette.js    — квантизация цветов и генерация Markdown-палитр
app.js        — состояние, извлечение кадров, навигация по режимам, экспорт
```

### Как извлекаются кадры

Скрытый элемент `<video>` перематывается на нужную секунду (`currentTime` →
событие `seeked`), текущий кадр рисуется на `<canvas>`, после чего:

- для превью — уменьшенная JPEG-копия (быстро, экономит память);
- для палитры — мини-копия 160 px, по которой считаются доминирующие цвета;
- для скачивания PNG — кадр в полном разрешении через `canvas.toBlob()`.

Перемотки сериализуются в очередь, поскольку у `<video>` одна позиция
воспроизведения. Извлечённые кадры кешируются по временной метке.

### ZIP без зависимостей

`zip.js` собирает архив методом STORE (без сжатия — PNG уже сжат), считая
CRC32 и формируя корректные local/central-заголовки с флагом UTF-8 для имён
файлов. Архивы открываются стандартными `unzip`, Проводником и т. д.

## Приватность

Видео и кадры существуют только в памяти вкладки. Ни байта не уходит на сервер;
при закрытии вкладки данные удаляются.
